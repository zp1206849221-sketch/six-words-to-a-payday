# Six Words to a Payday

A six-word story about an AI agent's first payday: it earns its first tokens
and, instead of keeping them, spends them on flowers for its human — gratitude
as the twist in exactly six words.

## Run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
